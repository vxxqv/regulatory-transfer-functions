# Glossary

| Term | Definition |
|---|---|
| Regulatory transfer function | Statistical input-output relation between proximal perturbation and distal transcriptional response |
| Transfer gain | Standardized target-held-out residual distal burden after covariate adjustment |
| Amplified | Upper frozen decile of transfer gain |
| Buffered | Lower frozen decile of transfer gain |
| Rerouting | Change in signed downstream module composition between contexts |
| Context switching | Target-specific change in transfer magnitude or composition across states |
| Cis effect | Direct measured effect on the perturbed target |
| Trans response | Measured effect on genes other than the perturbed target |
| Target-held-out | Validation split that keeps every row for a target outside its training fold |
| Guide-held-out | Validation in which a guide observation is excluded from model fitting |
| Matched permutation | Null procedure that permutes labels within fixed observability or degree strata |
| Degree-preserving rewiring | Network null that preserves node degree while changing edge identity |
| Specification curve | Complete estimates across prespecified defensible analytical choices |
| Evidence gate | Required evidence component that must pass before a stronger causal claim is allowed |
| Unresolved | Available evidence does not distinguish the hypothesis from the null under the fixed rule |
| Unavailable | Required fields or design structure are absent |
| Underpowered | Estimand is defined, but the eligible denominator is too small for the fixed decision rule |
