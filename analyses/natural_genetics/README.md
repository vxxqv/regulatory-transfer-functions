# eQTLGen directional validation

The validation links each trait-associated variant to its strongest significant cis-eQTL mediator among profiled perturbation targets. Knockdown response directions are reoriented to the mediator-increasing allele and compared with independent significant trans-eQTL directions. Alleles are harmonized explicitly. Uncertainty is clustered by variant, and the primary null reassigns perturbation targets within cell state and response-degree decile.
