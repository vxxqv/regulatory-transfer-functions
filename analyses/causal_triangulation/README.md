# Orthogonal Causal Triangulation and Mediation

The frozen denominator contains the three eligible loci in the deep-locus panel. Each locus must pass seven distinct evidence gates before it can be described as a convergent causal chain. Mediation is a separate, stricter gate and is not estimated when colocalization, harmonization, instrument-strength, heterogeneity, pleiotropy, or directionality assumptions fail.

The analysis retains the full denominator, all missing and contradictory evidence, candidate alternate genes, matched negative loci, instrument exclusions, sensitivity tests, and an evidence-tier assignment for every locus.

No locus passed all seven gates. GATA3-asthma and STAT3-inflammatory bowel disease each passed four gates and were graded tier 3. PTPN22-rheumatoid arthritis passed three gates and was graded tier 4. None of the 50 credible-set variants overlapped the released CD4 ATAC IDR peaks. H3K27ac overlapped 8 of 9 GATA3 variants and 17 of 40 STAT3 variants, so the prespecified ATAC-or-H3K27ac gate passed at those loci. STAT3 reached target-specific eQTL colocalization H4 = 0.964, but the gate remained unresolved because adequate regional coverage was not reported by the frozen source. No enhancer-to-gene gate passed, no mediation model was run, and no mediation claim is made.
