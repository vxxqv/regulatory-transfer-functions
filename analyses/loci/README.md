# Deep locus cards

Three loci were selected because a public disease credible set, an Open Targets L2G prediction, and a measured primary CD4 perturbation converge on the same gene. The fixed set is GATA3 for asthma, STAT3 for inflammatory bowel disease, and PTPN22 for rheumatoid arthritis. Credible-set posterior probabilities, L2G features, and signed downstream programs are retained separately. No allele-to-expression direction is asserted when the source does not provide it.
