# Cross-system replication

The K562 comparison supplied with GSE314342 is analyzed without selecting targets by their CD4 transfer phenotype. Observed signed log-fold-change correlations are contrasted with all three source-provided random correlations. Shared responses exceed the pooled random 97.5th percentile. High-confidence shared responses additionally have at least 10 differential genes in both systems. This rule is fixed before disease annotation.
