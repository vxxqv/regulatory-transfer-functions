# Independent confirmation freeze

This directory freezes the independent-data expansion before any new external outcome is opened. Candidate discovery is restricted to metadata needed to determine eligibility, power, provenance, and selection rank. Expression values, response vectors, effect estimates, significance values, outcome rankings, and outcome figures cannot be inspected during screening.

`candidate_manifest_template.tsv` is a header-only registry. Each candidate first receives a SHA256 hash of the exact metadata inventory used for eligibility and ranking. After selection, the candidate identifier, mapping, dataset role, rank, and unopened status are immutable. Before an outcome file can be opened, the complete file must receive a SHA256 checksum and any provider checksum must be recorded and verified. A changed mapping, role, or checksum stops the candidate.

`dataset_roles.tsv` excludes the development CD4 data, K562, RPE1, the earlier eight-target Th1 and Th2 comparison, and every other project outcome already inspected. A dataset seen only in a metadata audit may be reconsidered only if its outcome remains unopened and it passes the current gates without outcome-based selection.

The five linked blocks are:

1. Untouched portability in a human genetic perturbation transcriptomic dataset with at least 100 mapped CD4 targets and 500 response genes. It reuses the exact frozen ten-fold SHA256 target assignment, preprocessing, models, ablations, source-only feature selection, target bootstrap, calibration, coverage, target strata, and outcome-free covariate-shift fitting. The reduced model must beat the best competitive baseline with a paired interval above zero, corrected significance, acceptable calibration and coverage, and consistent fixed-stratum direction.
2. Replication in at least two independent primary human T-cell datasets, each containing at least two matched activation states, 50 mapped targets, 500 common genes, controls, and sufficient repeated units. The prior eight-target Th1 and Th2 result cannot serve as definitive replication.
3. Guide-by-donor reconstruction only when guide assignments, donor labels, controls, three supported guide efficacies, three donors for donor-held-out claims, 30 cells per guide-donor, and 500 genes are available. Null, linear, restricted spline, isotonic, breakpoint, and Hill models use guide-held-out and donor-held-out validation. Threshold and saturation claims stop below three supported doses.
4. State-compatible molecular evidence with verified build, identifiers, peak quality, time and state compatibility, and provenance. All eligible perturbed TFs and all signed-effect secondary TFs are frozen before occupancy inspection. No named pair, including GATA3 and EGR1, receives priority. Correlated curated databases count as one evidence type, with matched backgrounds, evidence tiers, directional-conflict reporting, direct-edge and cascade-timing tests, matched permutations, and degree-preserving rewiring.
5. Genome-wide immune-disease genetics only with complete summary statistics, ancestry-matched LD, immune-cell eQTLs, and state-relevant chromatin. The freeze specifies loci, credible sets, coloc priors and gates, MHC primary and sensitivity analyses, competitive covariates, negative controls, instrument checks, and mediation stopping rules. Integration compares supported and matched unsupported programs across guide concordance, cross-state core membership, untouched portability, information retention, and disease relevance.

Hypotheses H18 through H29 have directional expectations, endpoints, pass, fail, unavailable, and multiplicity rules in `hypotheses.tsv`. Every resampling family starts at 1,000 draws with fixed seeds. Additional draws are allowed only when a prespecified q-value decision lies within 0.005 of 0.05, using the same random stream.

The `novelty_and_result_gate` admits a branch only if it adds an independent evidence source or a materially distinct prespecified test, and if it can change or narrow a central conclusion while reporting effect size, uncertainty, denominator, calibration or falsification context, and a decision rule. Redundant methods, outcome-selected datasets, weak nominal-only results, and branches unable to change interpretation stop without substitution. A favorable P value alone is not a good result.

Run `python analyses/independent_confirmation/freeze.py` to regenerate `freeze_manifest.json`. Text hashes use LF-normalized UTF-8 bytes so raw, LF, and CRLF representations are equivalent. Binary hashes use exact bytes. Manifest paths are repository-relative.
